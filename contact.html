Contact & Corrections

This is a source archive rather than a general enquiries desk, and it is not staffed day to day. We do want to hear about genuine errors: a wrong date, a misquoted source, a broken link, or a document that should be added. Every correction is checked against a source before anything on the site is changed.

Report a correction

The fastest way to reach us is to open a correction report on the project's public GitHub page. You do not need a GitHub account to read existing reports, but you do need one (free to create) to submit a new one.

Open a correction report on GitHub →

Reports are public and reviewed when time allows. This is a small, unfunded project maintained at intervals rather than continuously, so please allow time for a response.

What to include

  • Which page and which specific statement you're asking about
  • What you believe is inaccurate or missing
  • A source we can check, if you have one

No email address is published for this project, and none is planned. Using the correction report above keeps a public, dated record of every request and how it was handled, which fits how this archive is meant to work.
